Solmu

A secure IoT gateway board I designed. It connects sensors to the cloud, and you set up the whole data flow in a JSON file. Change a sensor, a filter or the cloud, and the board picks it up over the air without a recompile or a reboot.

Why I built it

Connecting a sensor to a cloud shouldn’t mean rebuilding firmware every time something changes. And security shouldn’t be something you add later.

What it does

PipelinesData flow as configurationSensor inputs, filters, transforms and cloud outputs, all chosen in JSON and hot-reloaded
SecurityHardware-backed from day oneAn ATECC608B secure element signs payloads, encrypts credentials and authenticates devices
UpdatesThree signed OTA channelsFirmware with automatic rollback, configuration, and machine learning models
Edge MLClassify on the deviceTensorFlow Lite Micro runs as a pipeline stage, so time-critical decisions skip the cloud
CloudsNo vendor lock-inAWS IoT Core, Azure IoT Hub, GCP or any MQTT or HTTPS endpoint. Switch by editing config
PortalDesign in the browserA web app to build pipelines, manage devices and deploy to them over the air
